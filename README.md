# LED-Imaging-System
Over the course of summer 2025 and 2026, I developed an imaging system in partnership with Imperial College London's 10 by 5 Wind Tunnel. This repository contains the contents of some of the work I did, namely the open source driver board, and the copper core LED mount board.
